# 脏小猪（Drecksau）规则
<!-- rule-section: overview -->
## 概述

脏小猪（原名 Drecksau）是由 Frank Bebenroth 设计、KOSMOS 出版的快速卡牌游戏。每位玩家面前有一排干净的小猪，目标很简单：率先让自己所有的小猪都变脏！打出泥巴牌弄脏小猪，用谷仓保护它们，同时用雨水冲洗对手的小猪。
<!-- rule-section: game-objective -->
## 游戏目标

在《脏小猪》中，你照看着一排更喜欢泥巴的小猪。你的目标是比其他人更早让自己的所有小猪都变脏。
<!-- rule-section: components -->
## 组件

- 小猪牌（双面卡：一面干净、一面脏）
- 泥巴牌
- 雨水牌
- 谷仓牌
- 闪电牌
- 避雷针牌
- 农夫牌（给小猪洗澡）
- 谷仓门牌（锁住谷仓）
<!-- rule-section: setup -->
## 准备

1. 根据人数分配小猪牌：
   - **2 人局**：每人 5 只小猪
   - **3 人局**：每人 4 只小猪
   - **4 人局**：每人 3 只小猪
2. 将所有小猪牌**干净面朝上**放在每位玩家面前。
3. 将其余卡牌洗匀，每位玩家发 **3 张**手牌。
4. 剩余牌面朝下作为抽牌堆。

<!-- rule-section: how-to-play -->
## 游戏流程

![泥巴弄脏自己的猪，下雨冲洗，猪圈挡雨](/images/rules/drecksau/mud-weather.svg)

轮到你时，**必须打出 1 张**手牌，然后从抽牌堆**抽 1 张**。
<!-- rule-section: card-effects -->
### 卡牌效果

| 卡牌 | 效果 |
|------|------|
| **泥巴** | 将自己的一只干净小猪翻到**脏面** |
| **雨水** | 所有未受保护的脏小猪（所有玩家）被冲洗回**干净面** |
| **谷仓** | 放在自己的一只小猪上。保护该小猪免受雨水影响 |
| **闪电** | 摧毁对手的一个谷仓（移出游戏） |
| **避雷针** | 附加到自己的谷仓上。永久保护该谷仓免受闪电攻击 |
| **农夫** | 农夫给一只脏小猪洗澡——即使在谷仓里也逃不掉！ |
| **谷仓门** | 附加到自己的谷仓（谷仓内必须已有脏小猪）。保护小猪免受农夫影响 |
<!-- rule-section: special-rules -->
### 特殊规则

- 如果你的 3 张手牌**都无法出牌**，向所有玩家展示手牌后全部弃掉，重新抽 3 张。
- 一只小猪同时拥有谷仓、谷仓门和避雷针时**完全安全**，不受任何威胁。
- 对对手使用的卡牌（雨水、闪电、农夫）使用后弃掉。
- 抽牌堆用完时，将弃牌堆洗匀形成新的抽牌堆。
<!-- rule-section: winning -->
## 获胜条件

![第一个把每头猪都弄脏的人立即获胜](/images/rules/drecksau/winning.svg)

**率先**让自己所有小猪都翻到脏面的玩家立即获胜！

- <!-- rule-item: flow-turn -->
  **回合流程**

  你的回合：
  
  1. 从手牌 **打出 1 张**（必须）。
  2. 从抽牌堆 **抽 1 张**。
  
  可作用于 **自己的猪** 或 **对手的猪**（雨水、闪电、农夫针对对手）。
  
  ### 无法出牌？
  若 3 张牌均无法打出，亮牌给全体看，弃掉 3 张，重抽 3 张。
  
  ### 抽牌堆空？
  洗混弃牌堆组成新抽牌堆。

  **卡牌效果**

  | 牌 | 效果 |
  |----|------|
  | **泥巴** | 将 **自己的一头干净猪** 翻为脏 |
  | **雨水** | 所有 **无保护** 的脏猪（全体玩家）被洗 **干净** |

  谷仓 + 门 + 避雷针 = **免疫一切**。

- <!-- rule-item: flow-winning -->
  **获胜条件**

  **率先** 让 **全部** 猪同时显示 **脏面** 的玩家 **立即获胜**！
  
  ### 牌堆耗尽时
  若多次洗混后仍无人获胜，**脏猪最多** 的玩家胜。
  
  **速查：**
  - 对手有多头无保护脏猪时打 **雨水**
  - 对手刚建谷仓时用 **闪电**
  - **农夫** 杀伤力强 — 给重要谷仓加 **谷仓门**
