# 《领国者：带领你的阶级走向胜利》规则

## 游戏概述

在 **《领国者：带领你的阶级走向胜利》** 中，2–4 名玩家分别扮演虚构现代国家里的工人阶级、中产阶级、资本家阶级或国家。四个阶级的牌组与玩法截然不同，但工人、公司、金钱、税收、公共服务和政策投票会把所有人的选择连在同一套经济体系里。

## 游戏目标

带领你所属的阶级，在五轮游戏中累积繁荣与政治影响力。通过本阶级能达成的机会与目标获得**胜利分**；最终计分后，胜利分最高的玩家获胜。

## 游戏组件

- 主游戏板：政策轨道、议会、选举轨道、市场、银行与公共供应区
- 四套非对称的阶级玩家板、阶级牌组、起始牌、标记、金钱、影响力与工人
- 公司卡，以及私人经济所用的公司 / 工人组件
- 政策卡、议程卡、事件卡、选举组件、轮次与起始玩家标记
- 玩家辅助卡和各阶级专属规则册

## 游戏准备

1. 按玩家人数选择使用的阶级；未使用阶级与中立组件依官方设置摆放。
2. 摆好主游戏板、政策标记、市场供应、选举组件与轮次标记，具体依主规则书。
3. 每人拿取所属阶级的玩家板、牌库、起始牌、金钱、工人、影响力与其他组件；按本阶级设置摆放起始公司、工人与公共服务。
4. 准备公开的公司市场与政策 / 事件牌库，并按设置把起始玩家标记交给对应玩家。
5. 开始前，每人先阅读自己的**阶级目标与行动牌**。本阶级规则与卡牌文字优先于本页概览。

## 游戏流程

### 轮次循环：行动 → 生产结算 → 指定轮次举行选举 → 整备

游戏共进行 **5 轮**。在行动阶段，玩家按顺序轮流行动，通常从手中打出一张牌执行行动，或使用本阶级可用的通用行动。直到所有玩家都选择跳过；已跳过者通常不能在该行动阶段再行动。

![每个阶级用自己的行动牌，但所有行动都会流入同一套共享经济](/images/rules/hegemony/shared-economy.svg)

### 四个阶级

| 阶级 | 主要经营的事物 |
|---|---|
| **工人阶级** | 工人、就业、工会、消费与社会改革 |
| **中产阶级** | 自己的家庭与较小企业；既会受雇，也能雇人 |
| **资本家阶级** | 公司、投资、生产、工资、销售与利润 |
| **国家** | 公共服务、税收、补贴、公债与政治平衡 |

卡牌写明了本阶级行动的精确费用、限制与时机。一项好行动往往需要其他阶级间接配合：公司需要工人与消费者；家庭需要工作与收入；国家则要靠税收支持公共服务。

### 公司、工作与消费

公司通过相应阶级行动进入经济体系。它们须有合适的工人后才能生产。在生产阶段，符合条件的公司支付工资、提供商品或服务，并可能为其所有者带来收入；家庭则在允许的范围内用收入消费。请按主板、卡牌与阶级辅助卡写明的顺序和例外处理——许多效果取决于工人是否受雇、公司是否已配员，或商品是否可得。

### 政策与影响力

政策会改变所有人共用的规则：税收、劳动安排、福利、贸易等都会改变各阶级的成本与收益。玩家获得并花费**影响力**，以提出、支持或反对政策变化。政策卡与当前政策位置决定某些行动能否进行，以及其成本或收益。

![一项政策提案须在议会表决完成后才会成为法律](/images/rules/hegemony/policy-vote.svg)

### 选举

在选举轨道指定的轮次，暂停进行一次**选举**。按规定顺序处理竞选与投票效果，再调整政治代表权以及由此产生的政策机会。选举不是独立于经济之外的小环节：经济结果、阶级支持度和此前打出的卡牌，都可能影响选举。

### 生产与轮末

行动阶段后，按印刷顺序完成生产 / 经济流程：结算公司生产、工资、消费、税收、公共支出、公债，以及在该阶段触发的卡牌效果。随后进行轮末整备：依指示弃留手牌、补充公共展示、重置组件、推进轮次标记，并在需要时更新行动顺序。

## 游戏结束与计分

第 5 轮的最终流程完成后，依据主板、玩家板和目标 / 议程卡进行终局计分。将适用于你阶级的所有胜利分来源相加，最高分获胜；平手时按官方决胜规则处理。

## 特殊规则

- **非对称是设计本意。** 不要假设某阶级能做的行动其他阶级也能做；以卡牌文字和阶级辅助卡为准。
- **公开信息很重要。** 请在主板上持续留意政策位置、市场供应、就业、工资、税收和选举。
- **卡牌文字优先。** 若卡牌、政策或阶级规则册与本概览冲突，遵循官方文字。
- 第一次游玩建议使用官方推荐设置及入门引导；它们会建立游戏所预期的经济联系。
