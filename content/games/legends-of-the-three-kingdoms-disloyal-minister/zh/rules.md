# 三国杀：不臣之君 规则
<!-- rule-section: overview -->
## 概述

《不臣之君》是三国杀 2026 年推出的身份玩法扩展包，它彻底革新了经典的身份局模式。这不是武将扩充，而是引入了 **7 种全新身份玩法**，从根本上改变游戏的阵营对抗机制。支持 4-8 人游玩。**需要三国杀本体游戏。**
<!-- rule-section: game-objective -->
## 游戏目标

在《三国杀：不臣之君》中，你会进入一种拥有新阵营关系的身份玩法。你的目标是先看懂本局模式、找出自己一方，再完成该模式独有的胜利条件。
<!-- rule-section: components -->
## 组件

- 7 种新玩法的身份模式卡
- 专属武将：刘宏、董卓、张角
- 各模式专用的身份牌和规则卡
<!-- rule-section: the-7-identity-modes -->
## 7 种身份模式

![七种身份模式改变阵营，细则见模式卡](/images/rules/legends-of-the-three-kingdoms-disloyal-minister/seven-modes.svg)
本扩展包含 7 种截然不同的身份配置，每种都创造出独特的社交推理体验。每种模式改变了存在的身份、胜利条件以及联盟运作方式。
<!-- rule-section: key-design-philosophy -->
### 核心设计理念

不同于标准的主公/忠臣/反贼/内奸设置，这些模式引入了：
- **不对称信息** — 部分模式中某些玩家拥有更多信息
- **变化的联盟** — 某些身份可以在游戏中途改变阵营
- **全新身份类型** — 包括暴君、失心疯等
- **灵活的人数配置** — 每种模式有其最佳玩家人数
<!-- rule-section: how-to-use -->
## 使用方法

![选模式、发身份，再按标准回合进行](/images/rules/legends-of-the-three-kingdoms-disloyal-minister/how-to-use.svg)
1. 在游戏开始前选择 7 种身份模式之一。
2. 根据所选模式的设置规则分发对应的身份牌。
3. 遵循标准的三国杀回合流程（判定阶段 → 摸牌阶段 → 出牌阶段 → 弃牌阶段 → 结束阶段）。
4. 胜利条件因模式而异 — 参考具体模式的身份牌说明。
<!-- rule-section: general-rules -->
## 通用规则

- 三国杀的所有标准游戏机制保持不变（基本牌、锦囊牌、装备牌、武将技能）。
- 扩展包的专属武将（刘宏、董卓、张角）拥有与新身份模式协同设计的技能。
- 某些模式可能会修改特定规则（如玩家被淘汰时的处理方式）。

> **提示：** 7 种身份模式的详细规则印在随盒附带的模式卡上。请参考实体规则书和模式卡了解每种模式的具体设置、身份和胜利条件。

  **暴君董卓**

  ### 董卓 — 6体力，暴君
  
  - **诈觥：** 出牌阶段开始时，令一名其他角色选择：①本回合所有手牌视为【酒】并受你1点伤害；②视为对你用【酒】并造成1点伤害。
  
  - **凶戮：** 黑桃手牌可当【酒】；【酒】无次数限制；【酒】【杀】需要X张【闪】抵消（X=酒强化次数）。
  
  - **崩坏：** 锁定技，结束阶段若不为体力最小则失去1体力或减1上限。
  
  - **肆虐（暴君技）：** 锁定技，**每轮开始时回复所有体力**。每回合限一次，造成伤害时减1点体力上限并摸等同伤害值的牌。若因此杀死角色，重置该限制。

  **大忠似奸**

  ### 身份配置（7人）
  
  | 身份 | 数量 |
  |---|---|
  | **昏君** | 1 |
  | **奸臣** | 1 |
  | **忠臣** | 2 |
  | **义军** | 3 |
  
  ### 特殊规则
  - **昏君立即明置身份。**
  - **义军开局睁眼互认**（类似狼人杀）。
  - 昏君为**1号位**，体力上限与体力值**+1**。
  
  ### 胜利条件
  
  | 身份 | 条件 |
  |---|---|
  | **昏君** | 所有忠臣+所有义军死亡 |
  | **奸臣** | 所有忠臣死亡且昏君存活 |
  | **忠臣** | 所有奸臣+义军死亡且昏君存活 |
  | **义军** | 昏君死亡 |
  
  ### 核心博弈
  > 当最后一名忠臣死亡时，若义军已全灭 → **昏君与奸臣同时获胜！**
  
  - 义军不能无脑先推忠臣（否则奸臣捡漏）。
  - 忠臣≈传统内奸（需保主但不必单挑）。
  - 奸臣≈传统忠臣（不管反贼死活）。

  - 教主利用信息差迷惑失心为己所用。
  - 减上限惩罚有效保护失心不被随意盲杀。

  **各怀鬼胎**

  ### 身份配置（5人）
  
  | 身份 | 数量 |
  |---|---|
  | **主公** | 1 |
  | **忠臣** | 1 |
  | **奸贼** | 1 |
  | **恶贼** | 1 |
  | **逆贼** | 1 |
  
  ### 胜利条件——核心博弈
  
  | 身份 | 条件 |
  |---|---|
  | **主公** | 三种贼全部死亡 |
  | **忠臣** | 与主公一致（保护主公，消灭三贼） |
  | **奸贼** | **在没有忠臣存活的情况下**→主公死亡 |
  | **恶贼** | **在有忠臣存活的情况下**→主公死亡；**或**所有其他角色死亡 |
  | **逆贼** | 奸贼、恶贼**均存活**或**均死亡**的情况下→主公死亡 |
  
  ### 核心动态
  > 三贼条件相互矛盾——贼可能**保主公**以防止另一贼获胜！
  
  - 恶贼必须留忠臣活口→变相保皇党。
  - 逆贼需要两个同伙同时活或同时死→监控全局。
  - 奸贼要忠臣先死→追杀忠臣。
  
  ### 奖惩
  - 主公杀死忠臣→弃所有牌。
  - 杀死任意贼→摸**三张牌**。

  **合纵斗地主**

  ### 身份配置（4人）
  
  | 身份 | 数量 |
  |---|---|
  | **龙地主** | 1 |
  | **龙农民** | 1 |
  | **虎地主** | 1 |
  | **虎农民** | 1 |
  
  ### 两个阶段
  
  | 阶段 | 阵营结构 |
  |---|---|
  | **起义前** | 2v2：龙队 vs 虎队 |
  | **起义后** | 1v1v2：龙地主 vs 虎地主 vs 双方农民 |
  
  ### 起义机制
  - 地主获得**奴役**标记（每次发动或每轮结束+1）。
  - 标记达**9枚**→**起义触发！**
  
  ### 技能
  - **奴役** — 地主技：出牌阶段限一次，对己方农民造成1点伤害→**摸三张牌**。
  - **啸聚** — 农民技（起义后获得）：对原阵营地主造成的伤害**+1**。
  
  ### 胜利条件
  | 阶段 | 目标 |
  |---|---|
  | 起义前 | 敌方地主死亡 |
  | 起义后 | 另外两个阵营全部死亡（三方混战） |
  
  ### 核心博弈
  地主想靠奴役赚牌差——但每次发动都加速起义。一方发动后，另一方很难忍住不跟。**军备竞赛，最终同归于尽。**

- <!-- rule-item: flow-infernal-affairs -->
  **无间道**

  ### 身份配置（8人 — 4v4）
  
  每方阵营各含：
  
  | 角色 | 数量 | 说明 |
  |---|---|---|
  | **主帅** | 1 | 明置身份。可查看敌方全员身份牌。 |
  | **护卫** | 2 | 普通角色。不知道谁是内鬼。 |
  | **内鬼** | 1 | 牌背为对方阵营。正面归属敌方，实为自己人。 |
  
  ### 特殊规则
  1. 身份牌以**牌背颜色**区分阵营。
  2. 双方**主帅立即明置**。
  3. 每位主帅查看**对方阵营所有角色**的身份（知道自己安插的内鬼是谁）。
  4. 内鬼不知道主帅已知其身份。
  
  ### 击杀规则
  - 击杀与自己**实际阵营相同**的角色→**弃置所有牌**。
  - **主帅被击杀**→该阵营**内鬼立即明置身份**。
  
  ### 胜利：击杀敌方内鬼
  
  ### 终极讽刺
  > 主帅知道敌方内鬼身份，但不能明着打（会暴露内鬼）。护卫盲打——可能把自己内鬼狙死。
  
  **噩梦场景：** 护卫以为是敌人开了一枪……结果打死的是自家内鬼，直接输掉游戏。

- <!-- rule-item: flow-arrow-formation -->
  **锋矢奇谋**

  ### 身份配置（8人 — 4v4）
  
  每方4人：
  
  | 角色 | 说明 |
  |---|---|
  | **大将** | 初始隐藏。前锋死后才亮明。 |
  | **中军** | 标准角色。 |
  | **前锋** | **开局明置。** 体力上限+1、体力值+1。 |
  | **诱饵** | 被敌方击杀→己方大将弃置所有牌并暴露身份。 |
  
  ### 核心机制
  - **目标：** 击杀对方**大将**。
  - 前锋阵亡→己方大将身份亮明。
  - 诱饵阵亡→敌方大将身份暴露+弃置所有牌。
  
  ### 选将流程
  1. 双方大将各自查看己方中军、前锋、诱饵。
  2. 双方前锋同时明置。
  3. 双方大将同时选将亮将。
  4. 前锋明牌选将→其他角色同时选将。
  
  ### 特权
  - 前锋：明置+上限+1+多摸1牌。
  - 大将：体力上限+1。
  
  ### 战略深度
  > 牺牲前锋暴露对方大将，击杀诱饵引爆对方大将手牌。一场精心计算的牺牲与目标优先级博弈。
