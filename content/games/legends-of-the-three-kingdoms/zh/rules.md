# 三国杀规则
<!-- rule-section: 1-overview -->
## 1. 概述

三国杀是一款以三国时期为背景的多人卡牌游戏。每位玩家扮演一位三国英雄，拥有独特的技能。隐藏的身份决定了每个人的阵营和胜利条件。
<!-- rule-section: game-objective -->
## 游戏目标

在《三国杀》中，你是一名带着隐藏身份和武将技能的三国英雄。你的目标并不总相同：先辨认同伴，再帮助自己的阵营完成对应身份的胜利条件。
<!-- rule-section: 2-components -->
## 2. 组件
<!-- rule-ui: sidebar -->
- <!-- rule-item: 2-components-item-1 -->
  **身份牌** — 1 主公、2 忠臣、4 反贼、1 内奸（8 人局标准）
- <!-- rule-item: 2-components-item-2 -->
  **武将牌** — 25+ 三国武将，每位拥有独特技能
- <!-- rule-item: 2-components-item-3 -->
  **游戏牌** — 基本牌（杀、闪、桃）、锦囊牌和装备牌
- <!-- rule-item: 2-components-item-4 -->
  **体力牌** — 记录每位武将的当前体力
<!-- rule-section: 3-roles-victory-conditions -->
## 3. 身份与胜利条件

![主公忠臣对反贼，内奸独自获胜](/images/rules/legends-of-the-three-kingdoms/identity-win.svg)
| 身份 | 阵营 | 目标 |
|------|------|------|
| **主公** | 主公方 | 消灭所有反贼和内奸 |
| **忠臣** | 主公方 | 保护主公，消灭反贼和内奸 |
| **反贼** | 反贼方 | 消灭主公 |
| **内奸** | 独立 | 成为最后的存活者（主公必须最后消灭） |

除主公外，其他身份均保密。主公立即亮明身份。
<!-- rule-section: 4-setup -->
## 4. 准备

1. 根据人数选取身份牌，每人抽一张面朝下。主公亮明身份。
2. 主公获得 5 张武将牌选择；其他玩家各获得 3 张。
3. 每人选择一位武将并亮出。主公体力上限 +1。
4. 从主公开始（逆时针），每位玩家摸 4 张起始手牌。
<!-- rule-section: 5-game-flow -->
## 5. 游戏流程

![对距离内的人出杀，对方可闪](/images/rules/legends-of-the-three-kingdoms/turn-flow.svg)
每个回合包含 **六个阶段**，依次执行：

```
准备阶段
  ├─ 回合开始技能触发
  └─ "回合开始时"效果

判定阶段
  ├─ 按放入的逆序处理判定区内的延时锦囊
  ├─ 乐不思蜀
  ├─ 兵粮寸断
  └─ 闪电

摸牌阶段
  └─ 从牌堆摸 2 张牌

出牌阶段
  ├─ 使用手牌（每回合限出 1 张杀，除非技能/武器影响）
  ├─ 发动武将技能
  └─ 重铸

弃牌阶段
  └─ 手牌数弃至当前体力值

结束阶段
  └─ 回合结束技能触发
```

## 7. 基础规则
<!-- rule-section: distance -->
### 距离

距离等于两名角色之间的**最短路径**，沿顺时针或逆时针计算座位数。相邻角色距离为 1。

```
A —— B —— C —— D —— E

A 到 C：顺时针 2，逆时针 3 → 距离 = 2
A 到 D：顺时针 3，逆时针 2 → 距离 = 2
```

死亡角色不参与距离计算：

```
C 阵亡：  A —— B      D —— E

A 到 D：无连续路径 → 不可达
B 到 D：B → D = 距离 1（C 已不存在）
```

**调整项：**

| 调整项 | 效果 |
|--------|------|
| 武器 | 设定攻击范围（与距离独立） |
| -1 马 | 你到其他角色距离 -1 |
| +1 马 | 其他角色到你距离 +1 |
<!-- rule-section: dying-state -->
### 濒死状态

体力降至 0 时进入**濒死状态**：

1. 从濒死角色起逆时针，每名角色可以依次使用一张桃（或将酒当桃使用）进行救援。
2. 若濒死角色体力回复至 1 或以上，脱离濒死状态。
3. 若所有角色均不救，则该角色阵亡。

体力为 0 或负数的角色只能通过桃/酒救援——防止伤害不能阻止濒死。
<!-- rule-section: hand-limit -->
### 手牌上限

弃牌阶段，手牌数必须不超过当前体力值。超出的牌须弃置。

> "弃牌阶段弃牌"特指此弃置，是"弃置"的一种，后者还包括技能或卡牌造成的弃置。

## 8. 游戏术语
<!-- rule-section: skill-types -->
### 技能类型

| 类型 | 定义 |
|------|------|
| **锁定技** | 若能发动则必须发动或产生影响，不能放弃 |
| **限定技** | 一局至多发动一次 |
| **觉醒技** | 必须发动且仅一次，发动后永久改变状态并获得/失去技能 |
| **主公技** | 仅身份为主公时有效 |
| **转换技** | 阳/阴两种形态，每次发动自动切换；不发动当前形态无法切回 |

> 判断技能是否强制：看描述中是否有**"可以"**二字，而非看"锁定技"标签。无"可以"即强制，无论类型标签。

> "角色的技能"仅指武将技能。装备技能是角色"拥有"的但并非"角色的技能"。

---
<!-- rule-section: use-vs-play -->
### 使用 vs 打出

| 操作 | 定义 | 触发 |
|------|------|------|
| **使用** | 主动声明，指定目标，完整结算 | 触发"当你使用…"类技能 |
| **打出** | 响应事件出示，无目标，无使用效果 | 仅触发"当你打出/失去…"类技能 |

---
<!-- rule-section: discard-vs-phase-discard -->
### 弃置 vs 弃牌

- **弃置：** 将任一角色区域的牌置入弃牌堆
- **弃牌阶段弃牌：** 特指自己弃掉超出手牌上限的牌（属弃置的一种）

---
<!-- rule-section: losing-cards -->
### 失去牌

"失去牌"指原本属于你的牌离开你的控制区域。以下操作均属于"失去牌"：

| 操作 | 算失去？ |
|------|:------:|
| 使用手牌（如使用杀、锦囊） | ✓ |
| 打出手牌（如打出闪响应杀） | ✓ |
| 弃置（弃牌阶段或被技能弃置） | ✓ |
| 拼点牌（置入弃牌堆） | ✓ |
| 重铸牌（置入弃牌堆后摸牌） | ✓ |
| 装备被拆/被顺/被替换 | ✓ |

---
<!-- rule-section: recover -->
### 回复

增加体力（不能超过上限）。体力已满的角色不能回复。

> **受伤：** 体力值 < 体力上限。

---
<!-- rule-section: damage -->
### 伤害

| 术语 | 含义 |
|------|------|
| **来源** | 造成伤害的角色。来源死亡则视为无来源。 |
| **渠道** | 造成伤害的牌或技能。连环传导和转移保持原渠道。 |
| **属性伤害** | 火焰或雷电属性。未注明则为普通伤害。 |
| **连环伤害** | 因传导或转移产生的属性伤害，不会再次触发传导。 |

**体力流失 vs 伤害：**

| 区别 | 伤害 | 体力流失 |
|------|------|---------|
| 有来源 | ✓（造成伤害的角色） | ✗ |
| 触发卖血技 | ✓（如反馈、遗计） | ✗ |
| 进入濒死 | ✓ | ✓ |
| 连环传导 | ✓（仅属性伤害） | ✗ |
| 死亡奖惩 | ✓ | ✗ |

**防止伤害 ≠ 回复体力：**

> 伤害被防止后，视为没有造成伤害。不会触发受伤技能、濒死结算、连环传导或死亡奖惩。防止发生在伤害造成**之前**；回复发生在伤害造成**之后**。

---
<!-- rule-section: judgment -->
### 判定

1. 翻开牌堆顶一张牌作为**判定牌**。
2. 拥有改判技能的角色（如鬼才、鬼道）从当前回合角色逆时针依次决定是否改判，放弃后不可再改。
3. 判定牌生效，根据花色/点数决定结果。
4. 判定牌置入弃牌堆（除非技能特别说明，如天妒可收归手牌）。

> **判定牌不属于任何角色。** 不能成为目标，不能被获得（除非技能特别说明），其弃置不触发"失去牌"类技能。

---
<!-- rule-section: point-duel -->
### 拼点

**发起条件：** 双方都必须有手牌。没有手牌的角色不能发起也不能被选为目标。

> **拼点牌没有花色。** 只比较点数（A=1 最小，K=13 最大），除非技能另有说明。

**结算流程：**

1. 双方各选一张手牌，背面朝上同时置入处理区。
2. 同时亮出，比较点数：
   - 点数不同 → 大者**赢**，小者**没赢**
   - 点数相同 → 双方**都没赢**
3. 两张牌同时置入弃牌堆。
4. 根据结果执行后续效果。

---
<!-- rule-section: reforging -->
### 重铸

- 出牌阶段声明重铸，将该牌置入弃牌堆，然后摸一张牌。
- **不算"使用"**（不触发"当你使用……"类技能）。
- **算"失去"牌**。

---
<!-- rule-section: action-keywords -->
### 操作关键词

**"令"（A 令 B）** — A 发指令，B 执行，B 不能拒绝。

> 案例：貂蝉〖离间〗"**令**一名男性角色对另一名男性角色使用【决斗】。"→ 被令方必须执行。

> "你**可以**令 B…"中"可以"修饰 A 是否发令，而非 B 是否执行。

**"视为"** — 当作另一物使用，继承全部属性和效果，仍算"使用"。

> 案例：甘宁〖奇袭〗"将一张黑色牌当【过河拆桥】使用。"→ 可被无懈可击抵消。

**"转移"** — 将 A 的伤害转移给 B：防止 A 伤害 → 终止其结算 → B 受同来源、同渠道、同属性的伤害。

---
<!-- rule-section: choice-keywords -->
### 选择权

**"可以"** — 角色有选择权，可发动可不发动。一旦声明发动，第一个效果必须执行。

**"需"** — 有如何响应的选择权（必须响应，但可选方式）。

**"须"** — 强制执行，无选择空间。

**"任意数量"** — 可以为 0。

---
<!-- rule-section: connective-words -->
### 连接词

| 词 | 含义 |
|------|------|
| **"然后"** | 两效果先后执行。前后均为效果（非消耗）。 |
| **"并"** | 两操作**同时**执行。 |
| **"若如此做"** | 前置操作成功后才执行后续。失败则后续不生效。 |

---
<!-- rule-section: one-at-a-time-vs-simultaneous -->
### 依次 vs 同时

**有"依次"：** 一张张操作，每张结算完毕后才操作下一张。

**无"依次"：** 一次性同时操作。

> 案例：贯石斧弃两张牌是同时操作——陆逊不能先弃最后一张触发〖连营〗摸牌，再弃新牌来支付费用。

---
<!-- rule-section: choose-one -->
### 选择一项

多选一。**核心规则：** 某选项的所有效果都无法执行时，不能选该项。

> 案例：A 对没有手牌的 B 发动〖雌雄双股剑〗，B 无法选"弃一张手牌"，必须选"令 A 摸一张牌"。

---
<!-- rule-section: target-character -->
### 目标角色

使用结算中指牌的目标；伤害结算中指**当前**结算目标（可能因转移变化）。

> 案例：许褚〖裸衣〗后【决斗】对小乔 +1 伤害，小乔〖天香〗转移给 A——结算目标仍是小乔，A 不再 +1。

<!-- rule-section: 9-resolution-rules -->
## 9. 结算规则
<!-- rule-section: 9-1-effect-conflicts -->
### 9.1 效果冲突

**优先级：** 技能描述 ＞ 牌面信息 ＞ 游戏规则

> 案例：〖咆哮〗"无次数限制" vs 【杀】"出牌阶段限一次"——技能优先。

**否定原则：** 否定效果优先于肯定效果。"不能使用" > "可以使用"。

---
<!-- rule-section: 9-2-resolution-order -->
### 9.2 结算顺序

**插入结算：** 新事件中止当前流程 → 完成插入事件 → 继续原流程。

> 案例：夏侯惇受伤后发动〖刚烈〗→ 郭嘉受伤触发〖遗计〗→ 遗计结算完 → 回到郭嘉伤害结算 → 回到夏侯惇伤害结算。

**多角色顺序：** 从当前回合角色起**逆时针**依次结算/响应。

**同时机限制：**
- 只有一名角色能使用至多一张牌
- 同一技能每人至多选一次（计数类除外）

> 当前回合角色死亡时，改为"其死亡前的下家"起算。

---
<!-- rule-section: 9-3-priority-determination -->
### 9.3 优先级确定

同一时机能做多件事时：

> **武将技能 ＞ 装备技能 ＞ 使用牌 ＞ 游戏流程操作**

> 案例：装备【八卦阵】的主公曹操需出【闪】→ 先选〖护驾〗→ 再选〖八卦阵〗→ 最后用手牌。跳过高优先级后不可回头。

同优先级可自选顺序。

---
<!-- rule-section: 9-4-condition-check-timing -->
### 9.4 条件判定时机

条件是否满足在**轮到该角色选择时**判断。同时机内其他技能改变了状态，原不满足的技能可变为可发动。

---
<!-- rule-section: 9-5-compulsory-skills-do-not-miss-timing -->
### 9.5 锁定技不会错过时机

锁定技满足条件后立即触发并执行。即使玩家忘记声明，仍应补充执行——效果不会因遗漏而消失。

> 此条适用于所有锁定技和觉醒技。它们不能因疏忽被"跳过"。

---
<!-- rule-section: 9-6-cannot-respond-to-resolved-events -->
### 9.6 不能响应已结算完成的事件

事件结算完成后，不能再对其响应。

> 无懈可击只能在锦囊生效**前**打出。不能在锦囊结算完成后再打出。

> 同理，闪只能在杀造成伤害**前**响应。伤害已造成后，响应窗口即关闭。

---
<!-- rule-section: 9-7-prevent-damage-recover -->
### 9.7 防止伤害 ≠ 回复体力

伤害被**防止**后，视为没有造成伤害：

- 不触发"受到伤害后"类技能
- 不进入濒死结算
- 不触发连环传导
- 不触发死亡奖惩

**回复**体力时，上述事件均已发生——回复仅是在事后恢复体力值。

---
<!-- rule-section: 9-8-death-immediate-removal -->
### 9.8 死亡立即离场

角色死亡时，立即执行以下操作：

1. 弃置所有牌（手牌、装备、判定区）
2. 移除武将牌
3. 退出距离计算
4. 该角色不再存在于游戏中

> 死亡角色不能发动技能，除非技能明确说明死亡后仍可使用。

  ├─ 弃牌至手牌上限
  └─ "弃牌后"触发

结束阶段
  ├─ 回合结束锁定技
  └─ "回合结束时"可选技能

### 伤害事件链

```
伤害即将造成
  ↓
防止伤害窗口（如〖天香〗类技能）
  ↓
[若被防止 → 结束，无伤害]
  ↓
伤害造成
  ↓
"受到伤害后"触发（卖血技能）
  ↓

  ├─ 体力 > 0 → 结束
  └─ 体力 ≤ 0 → 进入濒死状态

  **游戏流程**

  ## 六个阶段（按顺序）
  
  | # | 阶段 | 内容 |
  |---|------|------|
  | 1 | **准备阶段** | 回合开始技能触发 |
  | 2 | **判定阶段** | 按放入逆序处理延时锦囊（乐不思蜀、兵粮寸断、闪电） |
  | 3 | **摸牌阶段** | 从牌堆摸 **2 张牌** |
  | 4 | **出牌阶段** | 使用牌、发动技能、重铸。每回合限 **1 张杀**。 |
  | 5 | **弃牌阶段** | 手牌弃至 **当前体力值** |
  | 6 | **结束阶段** | 回合结束技能触发 |
  
  ## 判定阶段详解
  
  1. 按**后放入先判定**顺序处理延时锦囊。
  2. 翻牌堆顶 → 按花色/点数执行效果。
  3. 改判技能（鬼才、鬼道）可修改结果。
  4. 判定牌置入弃牌堆。
  
  > 判定牌不属于任何角色，不能成为目标，不能被获得（除非技能特别说明）。
  
  ## 出牌阶段详解
  
  - 使用基本牌和锦囊牌
  - 装备武器、防具、马匹
  - 发动武将技能
  - **重铸**：弃一张牌摸一张（不算"使用"）
  
  **关键限制：** 每回合最多 1 张杀（除非技能或武器修改）。
  
  ## 回合方向
  
  从主公起逆时针依次进行。

  **装备牌**

  ## 装备栏
  
  每名角色有 4 个装备栏（每类限 1 件）：
  
  | 栏位 | 效果 |
  |------|------|
  | **武器** | 设定**攻击范围**（通常 2~5）。部分附带特殊效果。 |
  | **防具** | 被动防护（如八卦阵：需出闪时判定，红色则视为出闪）。 |
  | **+1 马**（防御） | 其他角色与你的**距离 +1** |
  | **-1 马**（进攻） | 你与其他角色的**距离 -1** |
  
  ## 攻击范围 vs 距离
  
  - **距离** = 两角色间最短路径（顺时针或逆时针）。
  - **攻击范围** = 由武器设定；决定杀可攻击的目标。
  - 相邻角色距离为 **1**。
  - 死亡角色**不参与**距离计算。
  - **顺手牵羊**要求目标距离 **1**。
  - 装备新物品替换同栏旧装备（旧装备弃置）。
  
  > 装备技能是角色"拥有"的但非"角色的技能"。涉及"角色的技能"的效果不包括装备技能。

- <!-- rule-item: flow-distance -->
  **距离与范围**

  ## 距离如何计算
  
  距离 = 两名角色之间的**最短路径**，沿顺时针或逆时针计算座位数。
  
  ```
  A —— B —— C —— D —— E
  
  A 到 C：顺时针 2，逆时针 3 → 距离 = 2
  A 到 D：顺时针 3，逆时针 2 → 距离 = 2
  ```
  
  ## 死亡角色不参与计算
  
  ```
  C 阵亡：  A —— B      D —— E
  
  A 到 D：无连续路径 → 不可达
  B 到 D：B → D = 距离 1（C 已不存在）
  ```
  
  ## 调整项
  
  | 调整项 | 效果 |
  |--------|------|
  | **武器** | 设定攻击范围（与距离独立） |
  | **-1 马** | 你到其他角色距离 -1 |
  | **+1 马** | 其他角色到你距离 +1 |
  
  ## 关键影响
  
  - 相邻角色距离为 **1**。
  - 只能对**攻击范围内**的目标使用杀。
  - **顺手牵羊**要求目标距离 **1** 以内。
  - **兵粮寸断**只能放在距离 **1** 以内的角色判定区。

- <!-- rule-item: flow-dying-death -->
  **濒死与阵亡**

  ## 濒死状态
  
  体力降至 **0** 时进入**濒死状态**：
  
  1. 从濒死角色起逆时针，每人可依次使用**一张桃**（或将酒当桃用）进行救援。
  2. 体力回复至 ≥ **1**，脱离濒死。
  3. 所有人均不救 → 角色**阵亡**。
  
  > 防止伤害不能阻止濒死。只有桃/酒才能从 0 回复体力。
  
  ## 死亡：立即离场
  
  角色阵亡时：
  
  1. 弃置**所有牌**（手牌、装备、判定区）
  2. 移除武将牌
  3. 退出距离计算
  4. 该角色不再存在于游戏中
  
  > 阵亡角色不能发动技能，除非技能明确说明可以。
  
  ## 奖惩
  
  | 阵亡身份 | 效果 |
  |----------|------|
  | **反贼** 被任何人杀死 | 凶手 **摸 3 张牌** |
  | **忠臣** 被主公杀死 | 主公 **弃置所有牌** |
  
  ## 胜负判定
  
  - **主公阵亡时反贼立即获胜**（即使反贼已全灭）。
  - 主公+忠臣在反贼**和**内奸均被消灭时获胜。
  - 内奸为唯一存活角色时获胜。

- <!-- rule-item: flow-terminology -->
  **游戏术语**

  ## 技能类型
  
  | 类型 | 定义 |
  |------|------|
  | **锁定技** | 若能发动则必须发动，不能放弃 |
  | **限定技** | 一局至多发动一次 |
  | **觉醒技** | 必须发动且仅一次，永久改变状态 |
  | **主公技** | 仅主公身份有效 |
  | **转换技** | 阳/阴形态，每次发动切换 |
  
  > 判断强制与否看**"可以"**二字，而非"锁定技"标签。
  
  ## 使用 vs 打出
  
  | 操作 | 定义 |
  |------|------|
  | **使用** | 主动声明，指定目标，完整结算 |
  | **打出** | 响应事件出示；无目标，无使用效果 |
  
  ## 失去牌
  
  "失去牌"= 牌离开你的控制区域：使用、打出、弃置、拼点、重铸、装备被拆/被顺/被替换——均算。
  
  ## 伤害术语
  
  | 术语 | 含义 |
  |------|------|
  | **来源** | 造成伤害的角色。来源死亡 → 无来源。 |
  | **渠道** | 造成伤害的牌/技能。转移保持原渠道。 |
  | **属性** | 火焰或雷电。未注明 = 普通。 |
  | **体力流失** | 无来源。不触发卖血技。 |
  
  > **防止伤害 ≠ 回复。** 防止 = 没造成伤害。回复 = 伤害后恢复体力。
  
  ## 判定
  
  翻牌堆顶 → 改判窗口 → 生效 → 牌入弃牌堆。
  
  > 判定牌不属于任何角色。不能成为目标，不能被获得。
  
  ## 拼点
  
  双方均须有手牌。点数：A=1 … K=13。大者赢。拼点牌**没有花色**。
  
  ## 选择权
  
  | 词 | 含义 |
  |------|------|
  | **可以** | 有选择权；声明后首效果必须执行 |
  | **需** | 有*如何*响应的选择权，但必须响应 |
  | **须** | 强制，无选择空间 |
  
  ## 连接词
  
  | 词 | 含义 |
  |------|------|
  | **然后** | 先后执行 |
  | **并** | 同时执行 |
  | **若如此做** | 前置成功才执行后续 |

- <!-- rule-item: flow-resolution -->
  **结算规则**

  ## 效果冲突
  
  **优先级：** 技能描述 > 牌面信息 > 游戏规则
  
  **否定原则：** 否定效果优先于肯定效果。"不能使用" > "可以使用"。
  
  ## 结算顺序
  
  **插入结算：** 新事件中止当前流程 → 插入事件结算完 → 继续原流程。
  
  **多角色顺序：** 从当前回合角色起**逆时针**依次结算。
  
  ## 优先级确定
  
  > **武将技能 > 装备技能 > 使用牌 > 游戏流程操作**
  
  跳过高优先级后不可回头。
  
  ## 锁定技不会错过时机
  
  锁定技满足条件立即触发。即使遗忘，效果仍须补充执行。
  
  ## 不能响应已结算事件
  
  事件结算完成后不能再响应。无懈可击必须在锦囊**生效前**打出。
  
  ## 防止伤害 ≠ 回复
  
  防止伤害 = 没造成伤害（无触发、无濒死、无传导）。回复 = 事后恢复体力。
  
  ## 死亡立即离场
  
  弃所有牌。移除武将。退出距离。无技能（除非特别说明）。

  ## 回合阶段时机
  
  ```
  准备阶段
    ├─ 回合开始锁定技
    └─ "回合开始时"可选技能
  
  判定阶段
    ├─ 闪电（若存在）
    ├─ 乐不思蜀（若存在）

    └─ 每回合至多 1 张杀
  
  弃牌阶段
    └─ 弃牌至手牌上限
  
  结束阶段
    └─ 回合结束技能
  ```
  
  ## 伤害事件链
  
  ```
  伤害即将造成
    ↓ 防止窗口
    ↓ [若被防止 → 结束]
    ↓ 伤害造成
    ↓ "受到伤害后"触发
    ↓ 体力检查：
      ├─ >0 → 结束
      └─ ≤0 → 濒死 → 桃/酒 → 救活或阵亡
  ```

  ```
  使用杀 → 指定目标
    ↓ 响应窗口（闪 / 防具 / 武将技能）
    ↓ 若未闪避 → 伤害计算
    ↓ 造成伤害 → 伤害后触发
  ```

  **游戏流程**

  ## 六个阶段（按顺序）
  
  | # | 阶段 | 内容 |
  |---|------|------|
  | 1 | **准备阶段** | 回合开始技能触发 |
  | 2 | **判定阶段** | 按放入逆序处理延时锦囊（乐不思蜀、兵粮寸断、闪电） |
  | 3 | **摸牌阶段** | 从牌堆摸 **2 张牌** |
  | 4 | **出牌阶段** | 使用牌、发动技能、重铸。每回合限 **1 张杀**。 |
  | 5 | **弃牌阶段** | 手牌弃至 **当前体力值** |
  | 6 | **结束阶段** | 回合结束技能触发 |
  
  ## 判定阶段详解
  
  1. 按**后放入先判定**顺序处理延时锦囊。
  2. 翻牌堆顶 → 按花色/点数执行效果。
  3. 改判技能（鬼才、鬼道）可修改结果。
  4. 判定牌置入弃牌堆。
  
  > 判定牌不属于任何角色，不能成为目标，不能被获得（除非技能特别说明）。
  
  ## 出牌阶段详解
  
  - 使用基本牌和锦囊牌
  - 装备武器、防具、马匹
  - 发动武将技能
  - **重铸**：弃一张牌摸一张（不算"使用"）
  
  **关键限制：** 每回合最多 1 张杀（除非技能或武器修改）。
  
  ## 回合方向
  
  从主公起逆时针依次进行。

  **装备牌**

  ## 装备栏
  
  每名角色有 4 个装备栏（每类限 1 件）：
  
  | 栏位 | 效果 |
  |------|------|
  | **武器** | 设定**攻击范围**（通常 2~5）。部分附带特殊效果。 |

  | **+1 马**（防御） | 其他角色与你的**距离 +1** |
  | **-1 马**（进攻） | 你与其他角色的**距离 -1** |
  
  ## 攻击范围 vs 距离
  
  - **距离** = 两角色间最短路径（顺时针或逆时针）。
  - **攻击范围** = 由武器设定；决定杀可攻击的目标。
  - 相邻角色距离为 **1**。
  - 死亡角色**不参与**距离计算。
  - **顺手牵羊**要求目标距离 **1**。
  - 装备新物品替换同栏旧装备（旧装备弃置）。
  
  > 装备技能是角色"拥有"的但非"角色的技能"。涉及"角色的技能"的效果不包括装备技能。

- <!-- rule-item: flow-distance -->
  **距离与范围**

  ## 距离如何计算
  
  距离 = 两名角色之间的**最短路径**，沿顺时针或逆时针计算座位数。
  
  ```
  A —— B —— C —— D —— E
  
  A 到 C：顺时针 2，逆时针 3 → 距离 = 2
  A 到 D：顺时针 3，逆时针 2 → 距离 = 2
  ```
  
  ## 死亡角色不参与计算
  
  ```
  C 阵亡：  A —— B      D —— E
  
  A 到 D：无连续路径 → 不可达
  B 到 D：B → D = 距离 1（C 已不存在）
  ```
  
  ## 调整项
  
  | 调整项 | 效果 |
  |--------|------|
  | **武器** | 设定攻击范围（与距离独立） |
  | **-1 马** | 你到其他角色距离 -1 |
  | **+1 马** | 其他角色到你距离 +1 |
  
  ## 关键影响
  
  - 相邻角色距离为 **1**。
  - 只能对**攻击范围内**的目标使用杀。
  - **顺手牵羊**要求目标距离 **1** 以内。
  - **兵粮寸断**只能放在距离 **1** 以内的角色判定区。

- <!-- rule-item: flow-dying-death -->
  **濒死与阵亡**

  ## 濒死状态
  
  体力降至 **0** 时进入**濒死状态**：
  
  1. 从濒死角色起逆时针，每人可依次使用**一张桃**（或将酒当桃用）进行救援。
  2. 体力回复至 ≥ **1**，脱离濒死。
  3. 所有人均不救 → 角色**阵亡**。
  
  > 防止伤害不能阻止濒死。只有桃/酒才能从 0 回复体力。
  
  ## 死亡：立即离场
  
  角色阵亡时：
  
  1. 弃置**所有牌**（手牌、装备、判定区）
  2. 移除武将牌
  3. 退出距离计算
  4. 该角色不再存在于游戏中
  
  > 阵亡角色不能发动技能，除非技能明确说明可以。
  
  ## 奖惩
  
  | 阵亡身份 | 效果 |
  |----------|------|
  | **反贼** 被任何人杀死 | 凶手 **摸 3 张牌** |
  | **忠臣** 被主公杀死 | 主公 **弃置所有牌** |
  
  ## 胜负判定
  
  - **主公阵亡时反贼立即获胜**（即使反贼已全灭）。
  - 主公+忠臣在反贼**和**内奸均被消灭时获胜。
  - 内奸为唯一存活角色时获胜。

  |------|------|
  | **使用** | 主动声明，指定目标，完整结算 |
  | **打出** | 响应事件出示；无目标，无使用效果 |
  
  ## 失去牌
  
  "失去牌"= 牌离开你的控制区域：使用、打出、弃置、拼点、重铸、装备被拆/被顺/被替换——均算。
  
  ## 伤害术语
  
  | 术语 | 含义 |
  |------|------|
  | **来源** | 造成伤害的角色。来源死亡 → 无来源。 |
  | **渠道** | 造成伤害的牌/技能。转移保持原渠道。 |
  | **属性** | 火焰或雷电。未注明 = 普通。 |
  | **体力流失** | 无来源。不触发卖血技。 |
  
  > **防止伤害 ≠ 回复。** 防止 = 没造成伤害。回复 = 伤害后恢复体力。
  
  ## 判定
  
  翻牌堆顶 → 改判窗口 → 生效 → 牌入弃牌堆。
  
  > 判定牌不属于任何角色。不能成为目标，不能被获得。
  
  ## 拼点
  
  双方均须有手牌。点数：A=1 … K=13。大者赢。拼点牌**没有花色**。
  
  ## 选择权
  
  | 词 | 含义 |
  |------|------|
  | **可以** | 有选择权；声明后首效果必须执行 |
  | **需** | 有*如何*响应的选择权，但必须响应 |
  | **须** | 强制，无选择空间 |
  
  ## 连接词
  
  | 词 | 含义 |
  |------|------|
  | **然后** | 先后执行 |
  | **并** | 同时执行 |
  | **若如此做** | 前置成功才执行后续 |

- <!-- rule-item: flow-resolution -->
  **结算规则**

  ## 效果冲突
  
  **优先级：** 技能描述 > 牌面信息 > 游戏规则
  
  **否定原则：** 否定效果优先于肯定效果。"不能使用" > "可以使用"。
  
  ## 结算顺序
  
  **插入结算：** 新事件中止当前流程 → 插入事件结算完 → 继续原流程。
  
  **多角色顺序：** 从当前回合角色起**逆时针**依次结算。
  
  ## 优先级确定
  
  > **武将技能 > 装备技能 > 使用牌 > 游戏流程操作**
  
  跳过高优先级后不可回头。
  
  ## 锁定技不会错过时机
  
  锁定技满足条件立即触发。即使遗忘，效果仍须补充执行。
  
  ## 不能响应已结算事件
  
  事件结算完成后不能再响应。无懈可击必须在锦囊**生效前**打出。
  
  ## 防止伤害 ≠ 回复
  
  防止伤害 = 没造成伤害（无触发、无濒死、无传导）。回复 = 事后恢复体力。
  
  ## 死亡立即离场
  
  弃所有牌。移除武将。退出距离。无技能（除非特别说明）。

  **游戏流程**

  ## 六个阶段（按顺序）
  
  | # | 阶段 | 内容 |
  |---|------|------|
  | 1 | **准备阶段** | 回合开始技能触发 |
  | 2 | **判定阶段** | 按放入逆序处理延时锦囊（乐不思蜀、兵粮寸断、闪电） |
  | 3 | **摸牌阶段** | 从牌堆摸 **2 张牌** |
  | 4 | **出牌阶段** | 使用牌、发动技能、重铸。每回合限 **1 张杀**。 |
  | 5 | **弃牌阶段** | 手牌弃至 **当前体力值** |
  | 6 | **结束阶段** | 回合结束技能触发 |
  
  ## 判定阶段详解
  
  1. 按**后放入先判定**顺序处理延时锦囊。
  2. 翻牌堆顶 → 按花色/点数执行效果。
  3. 改判技能（鬼才、鬼道）可修改结果。
  4. 判定牌置入弃牌堆。
  
  > 判定牌不属于任何角色，不能成为目标，不能被获得（除非技能特别说明）。
  
  ## 出牌阶段详解
  
  - 使用基本牌和锦囊牌
  - 装备武器、防具、马匹
  - 发动武将技能
  - **重铸**：弃一张牌摸一张（不算"使用"）
  
  **关键限制：** 每回合最多 1 张杀（除非技能或武器修改）。
  
  ## 回合方向
  
  从主公起逆时针依次进行。

  ## 装备栏
  
  每名角色有 4 个装备栏（每类限 1 件）：
  
  | 栏位 | 效果 |

  - **距离** = 两角色间最短路径（顺时针或逆时针）。

  - 死亡角色**不参与**距离计算。
  - **顺手牵羊**要求目标距离 **1**。
  - 装备新物品替换同栏旧装备（旧装备弃置）。

- <!-- rule-item: flow-distance -->
  **距离与范围**

  ## 距离如何计算
  
  距离 = 两名角色之间的**最短路径**，沿顺时针或逆时针计算座位数。
  
  ```
  A —— B —— C —— D —— E
  
  A 到 C：顺时针 2，逆时针 3 → 距离 = 2
  A 到 D：顺时针 3，逆时针 2 → 距离 = 2
  ```
  
  ## 死亡角色不参与计算
  
  ```
  C 阵亡：  A —— B      D —— E
  
  A 到 D：无连续路径 → 不可达
  B 到 D：B → D = 距离 1（C 已不存在）
  ```
  
  ## 调整项
  
  | 调整项 | 效果 |
  |--------|------|
  | **武器** | 设定攻击范围（与距离独立） |
  | **-1 马** | 你到其他角色距离 -1 |
  | **+1 马** | 其他角色到你距离 +1 |
  
  ## 关键影响
  
  - 相邻角色距离为 **1**。
  - 只能对**攻击范围内**的目标使用杀。
  - **顺手牵羊**要求目标距离 **1** 以内。
  - **兵粮寸断**只能放在距离 **1** 以内的角色判定区。

- <!-- rule-item: flow-dying-death -->
  **濒死与阵亡**

  ## 濒死状态
  
  体力降至 **0** 时进入**濒死状态**：
  
  1. 从濒死角色起逆时针，每人可依次使用**一张桃**（或将酒当桃用）进行救援。
  2. 体力回复至 ≥ **1**，脱离濒死。
  3. 所有人均不救 → 角色**阵亡**。
  
  > 防止伤害不能阻止濒死。只有桃/酒才能从 0 回复体力。
  
  ## 死亡：立即离场
  
  角色阵亡时：
  
  1. 弃置**所有牌**（手牌、装备、判定区）
  2. 移除武将牌
  3. 退出距离计算
  4. 该角色不再存在于游戏中
  
  > 阵亡角色不能发动技能，除非技能明确说明可以。
  
  ## 奖惩
  
  | 阵亡身份 | 效果 |
  |----------|------|
  | **反贼** 被任何人杀死 | 凶手 **摸 3 张牌** |
  | **忠臣** 被主公杀死 | 主公 **弃置所有牌** |
  
  ## 胜负判定
  
  - **主公阵亡时反贼立即获胜**（即使反贼已全灭）。
  - 主公+忠臣在反贼**和**内奸均被消灭时获胜。
  - 内奸为唯一存活角色时获胜。

  **游戏术语**

  ## 技能类型
  
  | 类型 | 定义 |
  |------|------|
  | **锁定技** | 若能发动则必须发动，不能放弃 |
  | **限定技** | 一局至多发动一次 |

  | **主公技** | 仅主公身份有效 |
  | **转换技** | 阳/阴形态，每次发动切换 |
  
  > 判断强制与否看**"可以"**二字，而非"锁定技"标签。
  
  ## 使用 vs 打出
  
  | 操作 | 定义 |
  |------|------|
  | **使用** | 主动声明，指定目标，完整结算 |
  | **打出** | 响应事件出示；无目标，无使用效果 |
  
  ## 失去牌
  
  "失去牌"= 牌离开你的控制区域：使用、打出、弃置、拼点、重铸、装备被拆/被顺/被替换——均算。
  
  ## 伤害术语
  
  | 术语 | 含义 |
  |------|------|
  | **来源** | 造成伤害的角色。来源死亡 → 无来源。 |
  | **渠道** | 造成伤害的牌/技能。转移保持原渠道。 |
  | **属性** | 火焰或雷电。未注明 = 普通。 |
  | **体力流失** | 无来源。不触发卖血技。 |
  
  > **防止伤害 ≠ 回复。** 防止 = 没造成伤害。回复 = 伤害后恢复体力。
  
  ## 判定
  
  翻牌堆顶 → 改判窗口 → 生效 → 牌入弃牌堆。
  
  > 判定牌不属于任何角色。不能成为目标，不能被获得。
  
  ## 拼点
  
  双方均须有手牌。点数：A=1 … K=13。大者赢。拼点牌**没有花色**。
  
  ## 选择权
  
  | 词 | 含义 |
  |------|------|
  | **可以** | 有选择权；声明后首效果必须执行 |
  | **需** | 有*如何*响应的选择权，但必须响应 |
  | **须** | 强制，无选择空间 |
  
  ## 连接词
  
  | 词 | 含义 |
  |------|------|
  | **然后** | 先后执行 |
  | **并** | 同时执行 |
  | **若如此做** | 前置成功才执行后续 |

- <!-- rule-item: flow-resolution -->
  **结算规则**

  ## 效果冲突
  
  **优先级：** 技能描述 > 牌面信息 > 游戏规则
  
  **否定原则：** 否定效果优先于肯定效果。"不能使用" > "可以使用"。
  
  ## 结算顺序
  
  **插入结算：** 新事件中止当前流程 → 插入事件结算完 → 继续原流程。
  
  **多角色顺序：** 从当前回合角色起**逆时针**依次结算。
  
  ## 优先级确定
  
  > **武将技能 > 装备技能 > 使用牌 > 游戏流程操作**
  
  跳过高优先级后不可回头。
  
  ## 锁定技不会错过时机
  
  锁定技满足条件立即触发。即使遗忘，效果仍须补充执行。
  
  ## 不能响应已结算事件
  
  事件结算完成后不能再响应。无懈可击必须在锦囊**生效前**打出。
  
  ## 防止伤害 ≠ 回复
  
  防止伤害 = 没造成伤害（无触发、无濒死、无传导）。回复 = 事后恢复体力。
  
  ## 死亡立即离场
  
  弃所有牌。移除武将。退出距离。无技能（除非特别说明）。

  **时机参考**

  ## 回合阶段时机
  
  ```
  准备阶段
    ├─ 回合开始锁定技
    └─ "回合开始时"可选技能
  
  判定阶段
    ├─ 闪电（若存在）
    ├─ 乐不思蜀（若存在）
    └─ 兵粮寸断（若存在）
  
  摸牌阶段
    └─ 摸 2 张牌
  
  出牌阶段
    ├─ 使用牌 / 发动技能 / 重铸
    └─ 每回合至多 1 张杀
  
  弃牌阶段
    └─ 弃牌至手牌上限
  
  结束阶段
    └─ 回合结束技能
  ```
  
  ## 伤害事件链
  
  ```
  伤害即将造成
    ↓ 防止窗口
    ↓ [若被防止 → 结束]
    ↓ 伤害造成
    ↓ "受到伤害后"触发
    ↓ 体力检查：
      ├─ >0 → 结束
      └─ ≤0 → 濒死 → 桃/酒 → 救活或阵亡
  ```
  
  ## 杀结算链
  
  ```
  使用杀 → 指定目标
    ↓ 响应窗口（闪 / 防具 / 武将技能）
    ↓ 若未闪避 → 伤害计算
    ↓ 造成伤害 → 伤害后触发
  ```

  **游戏流程**

  ## 六个阶段（按顺序）
  
  | # | 阶段 | 内容 |
  |---|------|------|
  | 1 | **准备阶段** | 回合开始技能触发 |
  | 2 | **判定阶段** | 按放入逆序处理延时锦囊（乐不思蜀、兵粮寸断、闪电） |
  | 3 | **摸牌阶段** | 从牌堆摸 **2 张牌** |
  | 4 | **出牌阶段** | 使用牌、发动技能、重铸。每回合限 **1 张杀**。 |
  | 5 | **弃牌阶段** | 手牌弃至 **当前体力值** |
  | 6 | **结束阶段** | 回合结束技能触发 |
  
  ## 判定阶段详解
  
  1. 按**后放入先判定**顺序处理延时锦囊。
  2. 翻牌堆顶 → 按花色/点数执行效果。
  3. 改判技能（鬼才、鬼道）可修改结果。
  4. 判定牌置入弃牌堆。
  
  > 判定牌不属于任何角色，不能成为目标，不能被获得（除非技能特别说明）。
  
  ## 出牌阶段详解
  
  - 使用基本牌和锦囊牌
  - 装备武器、防具、马匹
  - 发动武将技能
  - **重铸**：弃一张牌摸一张（不算"使用"）
  
  **关键限制：** 每回合最多 1 张杀（除非技能或武器修改）。
  
  ## 回合方向
  
  从主公起逆时针依次进行。

  **装备牌**

  ## 装备栏
  
  每名角色有 4 个装备栏（每类限 1 件）：
  
  | 栏位 | 效果 |
  |------|------|
  | **武器** | 设定**攻击范围**（通常 2~5）。部分附带特殊效果。 |

  | **+1 马**（防御） | 其他角色与你的**距离 +1** |
  | **-1 马**（进攻） | 你与其他角色的**距离 -1** |
  
  ## 攻击范围 vs 距离
  
  - **距离** = 两角色间最短路径（顺时针或逆时针）。
  - **攻击范围** = 由武器设定；决定杀可攻击的目标。
  - 相邻角色距离为 **1**。
  - 死亡角色**不参与**距离计算。
  - **顺手牵羊**要求目标距离 **1**。
  - 装备新物品替换同栏旧装备（旧装备弃置）。
  
  > 装备技能是角色"拥有"的但非"角色的技能"。涉及"角色的技能"的效果不包括装备技能。

- <!-- rule-item: flow-distance -->
  **距离与范围**

  ## 距离如何计算
  
  距离 = 两名角色之间的**最短路径**，沿顺时针或逆时针计算座位数。
  
  ```
  A —— B —— C —— D —— E
  
  A 到 C：顺时针 2，逆时针 3 → 距离 = 2
  A 到 D：顺时针 3，逆时针 2 → 距离 = 2
  ```
  
  ## 死亡角色不参与计算
  
  ```
  C 阵亡：  A —— B      D —— E
  
  A 到 D：无连续路径 → 不可达
  B 到 D：B → D = 距离 1（C 已不存在）
  ```
  
  ## 调整项
  
  | 调整项 | 效果 |
  |--------|------|
  | **武器** | 设定攻击范围（与距离独立） |
  | **-1 马** | 你到其他角色距离 -1 |
  | **+1 马** | 其他角色到你距离 +1 |
  
  ## 关键影响
  
  - 相邻角色距离为 **1**。
  - 只能对**攻击范围内**的目标使用杀。
  - **顺手牵羊**要求目标距离 **1** 以内。
  - **兵粮寸断**只能放在距离 **1** 以内的角色判定区。

- <!-- rule-item: flow-dying-death -->
  **濒死与阵亡**

  ## 濒死状态
  
  体力降至 **0** 时进入**濒死状态**：
  
  1. 从濒死角色起逆时针，每人可依次使用**一张桃**（或将酒当桃用）进行救援。
  2. 体力回复至 ≥ **1**，脱离濒死。
  3. 所有人均不救 → 角色**阵亡**。
  
  > 防止伤害不能阻止濒死。只有桃/酒才能从 0 回复体力。
  
  ## 死亡：立即离场
  
  角色阵亡时：
  
  1. 弃置**所有牌**（手牌、装备、判定区）
  2. 移除武将牌
  3. 退出距离计算
  4. 该角色不再存在于游戏中
  
  > 阵亡角色不能发动技能，除非技能明确说明可以。
  
  ## 奖惩
  
  | 阵亡身份 | 效果 |
  |----------|------|
  | **反贼** 被任何人杀死 | 凶手 **摸 3 张牌** |
  | **忠臣** 被主公杀死 | 主公 **弃置所有牌** |
  
  ## 胜负判定
  
  - **主公阵亡时反贼立即获胜**（即使反贼已全灭）。
  - 主公+忠臣在反贼**和**内奸均被消灭时获胜。
  - 内奸为唯一存活角色时获胜。

- <!-- rule-item: flow-terminology -->
  **游戏术语**

  ## 技能类型
  
  | 类型 | 定义 |
  |------|------|
  | **锁定技** | 若能发动则必须发动，不能放弃 |
  | **限定技** | 一局至多发动一次 |
  | **觉醒技** | 必须发动且仅一次，永久改变状态 |
  | **主公技** | 仅主公身份有效 |
  | **转换技** | 阳/阴形态，每次发动切换 |
  
  > 判断强制与否看**"可以"**二字，而非"锁定技"标签。
  
  ## 使用 vs 打出
  
  | 操作 | 定义 |
  |------|------|
  | **使用** | 主动声明，指定目标，完整结算 |
  | **打出** | 响应事件出示；无目标，无使用效果 |
  
  ## 失去牌
  
  "失去牌"= 牌离开你的控制区域：使用、打出、弃置、拼点、重铸、装备被拆/被顺/被替换——均算。
  
  ## 伤害术语
  
  | 术语 | 含义 |
  |------|------|
  | **来源** | 造成伤害的角色。来源死亡 → 无来源。 |
  | **渠道** | 造成伤害的牌/技能。转移保持原渠道。 |
  | **属性** | 火焰或雷电。未注明 = 普通。 |
  | **体力流失** | 无来源。不触发卖血技。 |
  
  > **防止伤害 ≠ 回复。** 防止 = 没造成伤害。回复 = 伤害后恢复体力。
  
  ## 判定
  
  翻牌堆顶 → 改判窗口 → 生效 → 牌入弃牌堆。
  
  > 判定牌不属于任何角色。不能成为目标，不能被获得。
  
  ## 拼点
  
  双方均须有手牌。点数：A=1 … K=13。大者赢。拼点牌**没有花色**。
  
  ## 选择权
  
  | 词 | 含义 |
  |------|------|
  | **可以** | 有选择权；声明后首效果必须执行 |
  | **需** | 有*如何*响应的选择权，但必须响应 |
  | **须** | 强制，无选择空间 |

  **结算规则**

  ## 效果冲突
  
  **优先级：** 技能描述 > 牌面信息 > 游戏规则
  
  **否定原则：** 否定效果优先于肯定效果。"不能使用" > "可以使用"。
  
  ## 结算顺序
  
  **插入结算：** 新事件中止当前流程 → 插入事件结算完 → 继续原流程。
  
  **多角色顺序：** 从当前回合角色起**逆时针**依次结算。
  
  ## 优先级确定
  
  > **武将技能 > 装备技能 > 使用牌 > 游戏流程操作**
  
  跳过高优先级后不可回头。
  
  ## 锁定技不会错过时机
  
  锁定技满足条件立即触发。即使遗忘，效果仍须补充执行。
  
  ## 不能响应已结算事件
  
  事件结算完成后不能再响应。无懈可击必须在锦囊**生效前**打出。
  
  ## 防止伤害 ≠ 回复
  
  防止伤害 = 没造成伤害（无触发、无濒死、无传导）。回复 = 事后恢复体力。
  
  ## 死亡立即离场
  
  弃所有牌。移除武将。退出距离。无技能（除非特别说明）。

- <!-- rule-item: flow-timing -->
  **时机参考**

  ## 回合阶段时机
  
  ```
  准备阶段
    ├─ 回合开始锁定技
    └─ "回合开始时"可选技能
  
  判定阶段
    ├─ 闪电（若存在）
    ├─ 乐不思蜀（若存在）
    └─ 兵粮寸断（若存在）
  
  摸牌阶段
    └─ 摸 2 张牌
  
  出牌阶段
    ├─ 使用牌 / 发动技能 / 重铸
    └─ 每回合至多 1 张杀
  
  弃牌阶段
    └─ 弃牌至手牌上限
  
  结束阶段
    └─ 回合结束技能
  ```
  
  ## 伤害事件链
  
  ```
  伤害即将造成
    ↓ 防止窗口
    ↓ [若被防止 → 结束]
    ↓ 伤害造成
    ↓ "受到伤害后"触发
    ↓ 体力检查：
      ├─ >0 → 结束
      └─ ≤0 → 濒死 → 桃/酒 → 救活或阵亡
  ```
  
  ## 杀结算链
  
  ```
  使用杀 → 指定目标
    ↓ 响应窗口（闪 / 防具 / 武将技能）
    ↓ 若未闪避 → 伤害计算
    ↓ 造成伤害 → 伤害后触发
  ```
