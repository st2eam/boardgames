# SETI: Space Agencies Rules

## Overview

**SETI: Space Agencies** (Tomáš Holek; Czech Games Edition, **October 2025**) is an expansion for *SETI: Search for Extraterrestrial Intelligence*. It requires the base game.

You lead an **asymmetric organization** — private tech, global research network, or fringe group — with its own powers, income, and starting position. The box also adds **three** new alien species, **42** project cards shuffled into the main deck, **Quick Start** cards that skip the slow opening round, and **signal tokens** that boost Scan.

With organizations the game is **4 rounds**: play only rounds **2, 3, 4, and 5**. Five rounds with organizations is not recommended (too long, not balanced).

## Components

- 11 asymmetric organization boards
- 21 Quick Start cards
- 42 project cards for the main deck (expansion icon)
- 10 signal tokens (unlimited if you run out — use substitutes)
- **3 new alien species:** Arkhos, Glyphids, Amoeba (boards, rule sheets, cards, and unique tokens)
- 3 Xenolab tiles, 1 Futurespan token
- 4 rival action cards (new starting card + one per new species)
- 3 long-term objective tiles (solo)
- Rulebook

## Always add (even without organizations)

Shuffle these into a normal SETI game whether or not you use organizations:

1. **42 cards** into the main deck.
2. **3 new aliens** with the original five; still draw **2** species at random.
3. **Signal tokens** within reach. New cards, some aliens, and some organizations award them.

Read a new species’ sheet only when it is discovered, same as the base game.

## Signal tokens

During a **Scan** action you may discard signal tokens: for each token, discard **1 extra** card from the card row and mark a signal in a matching sector.

The row refills only after the **entire** Scan, so you can spend **at most 2** tokens on one Scan. Effects that mark signals but are **not** a Scan cannot spend tokens.

## Playing with organizations

Organizations replace the base starting-income card and are used **together with Quick Start cards**.

### Setup changes

1. Prepare end-of-round stacks for rounds **2, 3, and 4** only (players + 1 cards each).
2. Starting player and starting scores (**1 / 2 / 3 / 4**) as in the base game.
3. All players start at **0 publicity** (not 4).
4. Deal each player **2** random organizations, **3** random Quick Start cards, and **4** cards from the main deck.
5. Each player keeps **1** organization and **2** Quick Start cards, plus all **4** deck cards. Resolve both Quick Start cards and the organization’s starting resources/effects **simultaneously**.

**First game:** use organizations numbered **1–4** (bottom-left). Give each player **1** of those four, **2** Quick Start cards (not 3), and 4 deck cards.

### Quick Start cards

- **Top half:** place the shown orbiter, traces, or signals. **Do not** take the usual bonuses (no orbit VP, no sector data, no discovery rewards, etc.).
- **Bottom half:** starting resources, VP, and other effects (often tied to what you marked above).
- Return the cards to the box afterward unless a card was **tucked for income**.

### Organization board

| Part | Rule |
|------|------|
| Starting resources / effects | Take these during setup, after choosing the org. |
| Income increases | Most orgs let you tuck cards. Resolve **after** starting resources, one tuck at a time (a tucked “draw a card” can feed the next tuck). Gain the tucked resource immediately. |
| Income | **Do not** take income at game start. Take it at the **start of rounds 3, 4, and 5**. |
| Passive power | Always on. |
| Once per round | Free action, once per round; mark the space when used. Income reminds you to clear the marker. |

### During play

Turns, Scan, Launch, Research, and final scoring follow the **base game**. Pass still rotates the solar system on the first pass of a round.

Do **not** play 4 rounds of Quick Start **without** organizations: the cards do not replace a missing round. If you try anyway, use the base starting-income card in place of an organization.

### FAQ notes (official)

- **Helion Assembly** and **Cosmos Strategy Group:** their top abilities look like triggerable missions but **are not**. A single trigger may mark both a real mission and one of these abilities.
- **Futurespan Institute:** only **one** prepared card at a time; it is not in hand. The once-per-round ability works only while its token is on the scoring track.

## 1–2 players

Before anyone drafts an organization or Quick Start cards, reveal **4** Quick Start cards. With an unused color, mark any orbiters, signals, or traces on the **top** halves. Ignore the bottom halves.

When a sector with **neutral** markers completes, treat them as another player. There are at most 2 neutrals, so they never win. If they have the second-most markers, leave **one** neutral marker in the sector.

The same 4-card reveal is optional in higher player counts, and can even be used in games **without** organizations to vary the opening board.

## Solo with organizations

Set up as a **2-player** game (neutral Quick Start recommended). The **rival gets no organization and no Quick Start**. Instead:

1. Shuffle the extra starting rival action card into their deck.
2. Rival publicity starts at **4**.
3. Except on 1-star: remove all **level I** objectives; stack II and III as usual and reveal 3 (all II). Shuffle the 3 long-term tiles and reveal **2**.

You pick your organization **after** seeing the neutrals and the 5 revealed objectives.

**Long-term objectives:** completing all three tasks **removes** the tile (you cannot spend it to block rival growth). At the end of rounds **2, 3, and 4**, the rival advances on the progress track once per **uncompleted** task still showing. They do not score leftover long-term tiles at game end. One trigger still marks only **one** task.

If the rival should add an advanced action card and none remain, they advance on the progress track instead.

## Scoring

Same as the base game after round 5’s last pass (gold-box cards, gold tiles, alien extras). Use the base SETI score tracker.

Do not read unused alien sheets in advance.
