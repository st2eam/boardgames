# TRIO (BBGE)

Plugin `trio` with editions `simple` | `spicy`.

- 36 cards (1–12 ×3), deal by player count (3–6)
- Reveal center or any player’s current low/high extreme
- Match three → collect trio; mismatch → bust and restore
- Win: 3 trios / 7s (simple) or 2 connected trios / 7s (spicy)

Card art: `public/images/bbge/trio/trio_01.webp` … `trio_12.webp`, `trio_back.webp`.
