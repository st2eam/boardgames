# UNO (BBGE)

One plugin `uno` with editions: `classic` | `flip` | `no-mercy`.

| Slug | defaultEdition |
|------|----------------|
| `uno` | classic |
| `uno-flip` | flip |
| `uno-show-em-no-mercy` | no-mercy |

Shared turn loop: match color/number/symbol → play or draw → UNO call/catch → empty hand scores to 500.

Edition-specific: Flip light/dark + Flip card; No Mercy stacking, 0/7 hands, mercy eliminate at 25.
