# 玩家能直接照着玩的规则写法

规则页的第一目标不是完整复述术语，而是让第一次接触游戏的人知道：**现在轮到我，我该做什么？**

## 先说你是谁、怎么赢

在“概览”之后立刻加一段 **游戏目标**。用自然的一两句话说清：玩家在这个主题里扮演谁、可以怎样压过或淘汰对手、最终如何获胜。不要另起一个页面栏目，也不要用“先记一句话”这类口号替代背景。

例如：

> 在《情书》中，你扮演其中一名追求者。你的目标是从其他追求者中脱颖而出：通过卡牌效果淘汰对手，或在终局以更高的手牌点数胜出，最终把信送到公主手中。

## 先写回合口令

每个主要回合都先给一句可执行的口令，再补充例外。例如：

- **摸 1 张 → 打 1 张。**
- **选 1 个行动：打牌压过桌面，或从桌面拿 1 张。**
- **放 1 枚棋子 → 结算它碰到的区域。**

不要先从“阶段”“资源区”“状态转换”等抽象名词开始。先说动作，玩家需要时再看原因与例外。

## 中文优先使用桌游口语

| 优先写法 | 首次出现时可补充的正式名词 | 避免单独使用 |
|---|---|---|
| 摸牌／拿牌 | 从牌堆抽取／从市场取得 | 获取一张组件 |
| 打牌／放牌 | 打出到桌面／放入自己的区域 | 执行卡牌部署 |
| 弃牌 | 放进弃牌堆 | 处置该卡 |
| 你面前的牌 | 投资组合、个人区域、展示区 | 个人持有区 |
| 大家都能拿的牌 | 市场、公共区 | 可用资源池 |
| 比大小／压过 | 比较组合强度 | 进行优先级判定 |
| 收走 | 获得并面朝下放在面前 | 捕获前置组合 |

专有行动名保留，但第一次写成“**打牌（Show）**”“**拿牌（Scout）**”这类双标签。之后优先用中文动作词。

## 信息顺序

每个规则块按这个顺序写：

1. **你是谁、怎么赢**：先用“游戏目标”交代身份、对抗和终局。
2. **你现在做什么**：一句话或编号步骤。
3. **怎么做算合法**：条件、数量、目标。
4. **做完发生什么**：奖励、转交、结算。
5. **容易踩坑的例外**：只列真正会改变选择的限制。

表格只用来比较选项、大小或计分；不要用表格代替回合步骤。

## 双语与流程页

- 英文同样先写动词：`Draw 1 → play 1`、`Play or take`。
- `flow.json` 的节点内容必须和规则页使用同一套口语动作词；流程节点标题应是“摸 1 张”“打 1 张”，而不是“资源获取阶段”。
- 配图要显示一个动作的前后状态，并配合页面中的动作词。

## 自检

首次阅读者只看每节的第一句，应当能回答：

- 轮到我先做哪一步？
- 我能选哪些动作？
- 我拿／打／放完后会发生什么？
- 什么时候结束、怎么算赢？
